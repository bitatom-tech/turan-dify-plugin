# Turan 图然 · Dify 插件

版本：v0.1.0

发布者：`bitatom` · 插件标识：`bitatom/turan`

将图然的商品视觉创作能力接入 Dify，让图片处理、模特穿搭、场景创意、图案设计与视频生成成为工作流的一部分。

一次配置 API Key，即可使用五大类共 29 项创作工具，以及「恢复任务结果」工具。

源码仓库：[bitatom-tech/turan-dify-plugin](https://github.com/bitatom-tech/turan-dify-plugin)。问题反馈：[GitHub Issues](https://github.com/bitatom-tech/turan-dify-plugin/issues)。

## 功能概览

| 分类 | 代表功能 |
| --- | --- |
| 设计素材 | 一键抠图、一键改款色、产品细节图、产品卖点四宫格 |
| 模特工具 | 模特换装、AI 虚拟模特、模特换姿势、模特买家秀 |
| 场景创意 | 风格海报智绘、运动场景智绘、智绘品宣图、风格克隆 |
| 图案工具 | 平铺转立体、局部重绘、款内图案提取、面料四方连续图案 |
| 视频类 | 产品视频 |

各工具的参数说明展示可用规格、参考价格与图片数量限制，最终以提交任务时图然的实时价格为准。

## 安装与授权

1. 打开 Dify 的「插件」页面，选择「通过本地文件安装」。
2. 上传 `turan-0.1.0.difypkg`，完成安装。
3. 登录 [Turan 图然](https://turan.design/)，没有账号时先注册。
4. 前往 [API Key 管理](https://turan.design/user-center/api-key)，创建并复制自己的密钥。
5. 打开 Dify 中「Turan 图然」插件的授权设置，填写 API Key 并保存。

调用工具需要图然账户有足够燃币。本地安装受 Dify 的插件管理策略约束；如提示签名校验限制，请联系 Dify 管理员处理。

## 网络连接

Dify 插件运行环境需要能够访问：

- 当前 Dify 的文件服务，用于读取工作流中选择的图片。自行部署 Dify 时，管理员需要配置插件运行环境可访问的文件服务地址。
- `https://turan.design` 和 `https://www.turan.design`，用于授权、工具配置、上传图片与生成任务。
- `https://rh-hk-images.xiaoyaoyou.com`，用于获取图然返回的结果文件；也支持保存在上述两个图然域名下的结果。

API Key 只发往受限制的图然 API 与上传接口，下载结果时不会携带密钥。图片通过 Dify 文件参数传入。

## 创建第一条工作流

1. 在工作流「开始」节点添加文件输入，用于上传原始图片。
2. 添加「Turan 图然」工具，选择需要的功能，例如「设计素材｜一键抠图」。
3. 将图片参数绑定到开始节点的文件变量，按需填写处理要求、比例与规格。
4. 将工具的 `files` 输出连接到后续节点，或绑定到工作流的输出节点。
5. 运行工作流。工具会等待任务完成，再将生成文件交给后续节点。

图片支持 PNG、JPEG、WebP，单张不超过 20 MiB。根据所选工具的提示上传原图、目标图或参考图。

同一组参考图通过一个多图入口上传，只补充一张时上传一张即可。各功能标明可上传的最多数量，图片按列表顺序对应图然官网的位置。

尺寸比例与规格采用文本参数，可直接填写或绑定上游变量。参数名显示默认值，下方列出本功能的完整可填值与规格参考价格；填写时使用说明中的实际值。各功能的比例与规格可能不同，插件会在提交前检查是否合法。

工具通过 `files` 输出图片或视频，并在可用时返回 `task_id`（任务 ID）、`workflow_code`（功能代码）、`status`（状态）和 `result_count`（结果数量）。

## 燃币与计费

调用消耗 API Key 所属图然账户的燃币，插件无需单独充值。各工具的规格说明显示参考价格，最终以提交任务时图然的实时价格为准。

不同功能的可选规格与价格不同，请在运行前查看所选工具的规格说明。

## 恢复已有任务

如果工作流中断或未能取回文件，请保留原任务 ID。添加「恢复任务结果」工具，填写该 ID，即可查询并取回已有任务的文件，无需重新生成。

恢复工具同样通过 `files` 输出结果，但不会自动续跑已经失败的工作流。

单次工具调用最长等待 8 分钟，Dify 工作流或网络服务也可能设置执行时限。建议关闭生成节点的自动重试，提交状态不确定时优先查询原任务，避免重复创建。

## 隐私与数据处理

插件会将你选择的图片和业务参数发送给图然，用于完成所请求的生成。图片和处理要求可能包含个人信息，请在提交前阅读[插件隐私政策](https://github.com/bitatom-tech/turan-dify-plugin/blob/main/PRIVACY.md)及[图然服务隐私政策入口](https://turan.design/login/register)。在图然页面点击「隐私政策」即可打开政策弹窗。

插件仅在 Dify 存储中为每个密钥命名空间保存最新一条任务恢复记录。图片、工作流记录及图然服务端数据的保留与删除方式见隐私政策。
